<h1>Network Info C</h1>

<p>
A small command-line tool written in C that displays basic network information about the current computer.
</p>

<h2>About this project</h2>

<p>
This is my first larger programming project and one of my first projects published on GitHub.
</p>

<p>
I am currently doing an apprenticeship in Platform Development and wanted to improve my programming skills while working on something related to networking and system administration.
</p>

<p>
The goal of this project is to learn C by building a useful command-line tool step by step.
</p>

<h2>Planned features</h2>

<ul>
  <li>Display the hostname</li>
  <li>Display the IPv4 address</li>
  <li>Display the subnet mask</li>
  <li>Display the CIDR prefix</li>
</ul>

<h3>Possible future features</h3>

<ul>
  <li>Default gateway</li>
  <li>DNS servers</li>
  <li>MAC address</li>
  <li>DHCP information</li>
</ul>

<h2>Current status</h2>

<p>
The project is currently in development while I am learning C.
</p>

<h2>Build</h2>

<p>
This project currently uses GCC on Windows.
</p>

<pre><code>gcc network-info.c -o networkinfo.exe</code></pre>

<h2>Run</h2>

<p>
In PowerShell:
</p>

<pre><code>.\networkinfo.exe</code></pre>
